# 07 — 选择并记住 B 沉浸封面主题

**What to build:** 观看者可以在 A 报刊信息卡与 B 沉浸封面之间切换，两个主题呈现相同 generation snapshot 和 share target，并在下次打开面板时恢复上次选择。

**Blocked by:** 05 — 分享当前分P与播放位置

**Status:** ready-for-agent

- [ ] 首次使用默认选择 A 报刊信息卡；切换 A/B 后记住上次选择，并在后续打开分享面板时恢复。
- [ ] 切换主题只改变视觉表现，不重新获取视频信息、不改变 generation snapshot、字段集合、share target 或文案语义。
- [ ] B 主题以 1080×1440 的 3:4 画布导出，封面全出血、底部深色渐变、文字为白色，并保持已批准的信息层级。
- [ ] B 主题标题最多三行并按内容压力执行 19→17→15px 阶梯降级；底端遮罩保证标题、UP 主、数据和身份信息可读。
- [ ] 四项统计使用毛玻璃数据条，BV/AV 同时可见；二维码位于独立白卡并保留安静区，可见链接可完整换行。
- [ ] 分P与时间标签在启用时位于顶部毛玻璃胶囊，未启用时不占位；缺少分P标题和统计时遵守既定 `P<number>` 与 `--` 规则。
- [ ] B 主题使用对应深色分享面板；窄视口下海报收窄、控制区换行且所有动作仍可访问。
- [ ] A/B 两主题的 poster preview、复制 PNG 和下载 PNG 保持内容一致，并通过长标题、长链接、缺失统计和多分P场景视觉验收。
- [ ] 页面入口随记住的主题呈现已批准的 A 细边框或 B 深色实心样式，同时保持海报图标和“生成海报”文案，不与官方分享动作混淆。
- [ ] 主题默认值、持久化恢复、切换不改变数据语义以及 B 标题字号规则具有外部行为测试。
