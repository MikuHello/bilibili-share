# 01 — 恢复真实封面请求与图片导出

**What to build:** 更正封面域许可，构建并核对真实安装版本，在原故障视频走通请求、解码、预览到图片导出。此票可使用现有海报外观验收网络修复，不等待新设计。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 封面声明采用 hdslb.com 所需范围，保留API/短链精确域，不使用全域通配。
- [ ] 在真实管理器中核对构建与安装版本，原故障视频完成请求、有效图片解码、预览及PNG导出。
- [ ] 保留无凭据的请求结果、类型/字节、解码尺寸与导出证据；不把静态声明检查或原型通过记为真实修复。
- [ ] 按批准规格的领域核心/浏览器副作用接缝执行适当TDD、类型检查和集成验证；完成code-review及提交，记录真实证据和未验证项。

**交付约定：** 本票属于已批准的默认主题与分享面板整批改版。遵守本计划spec与整批交付约定；可内部独立验证和提交，不向主人逐票交付或要求安装中间版本。全部完成后统一提供最终构建与验收结果。
