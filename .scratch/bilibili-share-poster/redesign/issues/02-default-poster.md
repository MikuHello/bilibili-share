# 02 — 落地唯一默认海报与完整内容适配

**What to build:** 用已批准默认海报替换A/B，真实快照生成预览及1080×1440导出；长标题、长昵称、非横版封面和完整长链接均遵守定稿规则。忽略旧海报主题偏好。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 唯一默认主题替换A/B选择及旧主题偏好影响；保持定稿雾蓝配色、官方标识/图标和署名层级。
- [ ] 画布1080×1440，封面1080×608区域contain完整保留，非横版居中补底色。
- [ ] 标题按真实浏览器排版依次尝试64/60/56/52/48px，再按剩余高度省略；不推断主副标题。
- [ ] 昵称最多两行、34/32/30px后省略；BV/AV及四项统计可见，缺失为--，万/亿规则保持。
- [ ] 24px网址完整换行；页脚可增长而画布不变；二维码白底静区完整，正文无分P/时间标签。
- [ ] 真实PNG验证长标题/昵称、不同封面比例、长链接、尺寸及扫码目标；预览和导出一致。
- [ ] 按批准规格的领域核心/浏览器副作用接缝执行适当TDD、类型检查和集成验证；完成code-review及提交，记录真实证据和未验证项。

**规格覆盖：** 9–22、43；51的海报独立配色、58的旧主题偏好。

**交付约定：** 本票属于已批准的默认主题与分享面板整批改版。遵守本计划spec与整批交付约定；可内部独立验证和提交，不向主人逐票交付或要求安装中间版本。全部完成后统一提供最终构建与验收结果。
