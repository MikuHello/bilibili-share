# 05 — 落地第四版操作面板与完整导出动作

**What to build:** 按最终原型组织桌面/窄屏面板、标记选项、文案区独立复制按钮、常显详细信息、并列海报/组合复制及海报下方下载图标。真实复制、下载和失败替代路径可用，关闭与键盘导航完整。

**Blocked by:** 02、03。

**Status:** ready-for-agent

- [ ] 最终第四版面板桌面左右分栏、窄屏纵向；16px居中标题、透明细叉、小圆角、轻阴影、中性遮罩、统一底色及无贯穿分隔线。
- [ ] 上方标记选项、分享文案右侧独立两种复制、常显详细信息；底部并列复制海报/组合复制，海报下方居中下载图标。
- [ ] 不包含口号、Markdown勾选模式或原型评议控件；320/390px窗口可滚动且动作可达。
- [ ] 真实用户手势验证PNG、普通文案、Markdown、组合复制及下载；下载为同一1080×1440成品。
- [ ] 组合复制用普通文案，写入失败降级普通文案并说明海报需单独处理；接收方选择格式的提示准确。
- [ ] 复制海报失败保留预览并引导下载；所有加载/更新/部分失败状态正确展示可用动作。
- [ ] 关闭按钮/Escape/遮罩统一关闭，焦点限制在面板并返回可用入口；图标有名称、提示、可见焦点和正确禁用状态。
- [ ] 按批准规格的领域核心/浏览器副作用接缝执行适当TDD、类型检查和集成验证；完成code-review及提交，记录真实证据和未验证项。

**规格覆盖：** 31–45、53–54；46–49的最终状态展示。

**交付约定：** 本票属于已批准的默认主题与分享面板整批改版。遵守本计划spec与整批交付约定；可内部独立验证和提交，不向主人逐票交付或要求安装中间版本。全部完成后统一提供最终构建与验收结果。
