# 品牌标识微调第五版 — THROWAWAY

状态：第五版已由主人批准为默认主题设计原型；非实现 spec、非生产实现。批准范围以 ../approval.md 为准。各版待评议文字为历史。

运行：仓库根目录执行 `python3 -m http.server 8767 --bind 127.0.0.1 --directory .scratch/bilibili-share-poster/redesign/prototype`，打开 http://127.0.0.1:8767/ 。

## 已确认要求

海报独立配色、单版图像主导、杂志署名栏、全 UI 风格统一；长短链接均为备用信息，置于最底部、用线条分隔，未来新增主题时大体保留同一链接结构。未来多主题仅作为设计约束，本轮不实现主题选择。

## 当前提案

- 完整原封面与 1080×1440 比例暂沿用。
- 正文 #233B41、辅助 #5F777B、画布 #DCE8E7、署名区 #EEF4F1、分隔线 #A9BDBC。实色文字，无额外描边/文字阴影，不给每块文字加独立底色。
- Logo 使用官方原始形状和品牌蓝；UP 标记为官方路径着粉色；点赞/投币/收藏均取自原生工具栏形状。来源细节见 assets-sources.md。
- 署名栏左侧依次为 UP 昵称、统计、BV/AV；右侧为二维码及观看引导。二维码码点黑白，白底与静区保留，外部以细框承托。
- 备用链接为独立页脚，分隔线与署名栏对齐；短链/长链保持同一字段顺序、位置与高度，不侵占二维码区。
- 下拉框只是长短链场景演示；上方深浅色按钮只是页面外观模拟，两者均不属于产品主题控件。
- 降级提示仍为操作面板片段中的小号灰字“已使用完整链接”。短链场景隐藏提示。
