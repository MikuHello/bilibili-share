# 真实刊物视觉参考 — 待主人选择

Status: reference research only — NOT an approved design

以下是实际刊物图片，不是项目原型。设计解读是本轮的比较建议；选定后仍要用真实 Bilibili 视频、中文长标题、统计和可扫描二维码检验适配性。

## 1. Kinfolk — 图像占主导

可借鉴：强图像焦点、克制的标题层级、少而明确的信息。适合探索沉浸式海报；需要解决视频横封面进入竖画布后的裁切。

[Kinfolk Issue 50 官方来源](https://www.kinfolk.com/product/issue-50/)

![Kinfolk Issue 50](https://ik.imagekit.io/kinfolk/wp-content/uploads/2024/05/K50_cover-1000x1235.png)

## 2. Cereal — 留白与摄影排版

可借鉴：浅色纸面、精确留白、图片与小字号辅助信息的比例。适合探索主人要求的浅色、高质感方向；不能把留白做成无意义的大空区。

[Cereal Vol. 18 实物内页来源](https://www.patikakitabevi.com/cereal-volume-18)

![Cereal Vol. 18 内页](https://www.patikakitabevi.com/UserFiles/Fotograflar/4855-cereal-volume-18-71zyhyzcv0l-jpg-71zyhyzcv0l.jpg)

## 3. Monocle — 信息密度与编辑网格

可借鉴：清晰的信息分级、图像与多类信息的网格关系。适合比较统计/身份信息较多时的秩序；不照搬其密集栏目与文字。

[Monocle Issue 184 官方来源](https://monocle.com/shop/product/june-2025-issue-184/)

![Monocle Issue 184](https://cdn.swell.store/monocle/682daf08ac663b0012546a1a/9b11f1226ec8ece92cb613f7a067b391/COVER_184_BACKGROUND.jpg)

## 接下来的比较方式

先由主人选择视觉语言，再用同一真实视频制作两到三个有明确区别的候选版式。每个方案必须解释：封面如何处理、长标题如何读、图标统计如何安排、二维码与链接如何融入、手机上是否清晰。

这些参考图是外链，未下载进仓库；如来源失效重新查找原来源，不用合成图冒充真实刊物参考。
