# 默认主题与分享面板改版 · 实现规格

Status: APPROVED — spec approved; ticket breakdown awaiting owner approval; implementation not started
Date: 2026-09-05
Plan: bilibili-share-poster/redesign

本规格由已经确认的 discovery 与最终原型合成。主人于2026-09-05回复“批准”，确认本实现规格。下一步审阅拆票方案，批准后生成新工单；不继续旧工单，不将规格批准视为直接实施授权。

## Problem Statement

当前安装脚本的封面请求被管理器域名许可拒绝，却将错误合并为英文占位并允许产生缺封面的海报。当前 A/B 海报、固定深色面板与独立矩形入口不符合已经重新确认的设计。常驻技术降级信息、折叠的关键动作以及全局 Markdown 模式增加了操作负担。

需要将已批准的默认主题及第四版面板落实为真实可用的用户脚本：正确取得真实封面，保持一个可信的分享落点，提供清晰的复制/下载动作，在长内容、浅深色页面和可恢复失败下保持可用。

## Solution

保留一套独立雾蓝配色的 1080×1440 默认分享海报，以完整封面、自动换行标题、署名与统计、二维码和底部完整网址构成作品。分享面板采用已经批准的第四版布局和原生界面层级；跟随实际页面浅深模式，海报不随之改色。

“标记当前分P / 标记当前时间”只改变海报二维码与底部链接，不添加海报正文标签。文案复制与 Markdown 复制是两个独立动作，共享“详细信息”选择。复制海报与组合复制并列；下载图标位于海报下方。封面失败时提供文案与重试，不输出占位海报。

本计划覆盖这套设计在现有产品中的完整落地和必要故障修复。未被本轮明确替代的快照、暂停恢复、分享目标验证、浏览器兼容和本地生成边界继续保留。

## User Stories

1. As a 视频观看者, I want 在官方分享右侧找到“生成海报”, so that 可以从已有工具栏进入分享面板。
2. As a 视频观看者, I want 入口的图标、颜色、大小和悬停融入工具栏, so that 它看起来属于同一页面。
3. As a 视频观看者, I want 原生分享仍保持原有用途, so that 新入口不会替代官方分享。
4. As a 视频观看者, I want 页面入口不可挂载时仍有脚本菜单入口, so that 支持的视频仍能生成海报。
5. As a 视频观看者, I want 点击入口立即看到加载状态并捕获稳定快照, so that 分享对应打开面板时的视频和播放位置。
6. As a 视频观看者, I want 只在原本播放且脚本暂停的情况下恢复同一视频, so that 关闭面板不会改变原本暂停或新视频的状态。
7. As a 视频观看者, I want 重复点击入口保留已有面板和快照, so that 不重复请求或捕获不同位置。
8. As a 视频观看者, I want 切换视频或分P时关闭旧面板, so that 不会导出旧视频内容。
9. As a 分享者, I want 首次打开就是唯一的默认海报, so that 不再选择 A/B。
10. As a 分享者, I want 海报使用批准的雾蓝配色、官方品牌标识和统计图标, so that 作品保持定稿的视觉层级。
11. As a 分享者, I want 完整保留原视频封面, so that 画面不会被重新裁切或替换。
12. As a 分享者, I want 竖版和方形封面在固定区域居中并补底色, so that 不破坏整张海报结构。
13. As a 分享者, I want 标题按原文顺序自动换行, so that 不依赖人为主副标题拆分。
14. As a 分享者, I want 长标题有限缩字后才省略, so that 保持阅读大小与信息量的平衡。
15. As a 分享者, I want 被海报省略的完整标题仍在文案中, so that 复制时不会丢失正文。
16. As a 分享者, I want UP昵称最多两行、有限缩字后省略, so that 署名不侵占统计和二维码。
17. As a 分享者, I want 海报同时包含 BV、AV 与四项统计, so that 身份和数据快照都清楚可见。
18. As a 分享者, I want 缺失统计显示为 `--`, so that 不把未知误读为零。
19. As a 分享者, I want 海报统计紧凑显示而详细文案保留精确值, so that 两种载体各自适合阅读。
20. As a 接收者, I want 二维码清晰、保留白底和静区, so that 可以识别观看入口。
21. As a 接收者, I want 最底部地址栏完整显示网址并允许换行, so that 无法扫码时仍可使用链接。
22. As a 接收者, I want 二维码与可见网址具有同一落点, so that 两种入口不会指向不同视频或位置。
23. As a 分享者, I want 默认从视频默认开头分享, so that 未开启标记时不隐含当前分P或时间。
24. As a 分享者, I want 标记分P只改变二维码与链接的分P目标, so that 海报正文保持相同视频内容。
25. As a 分享者, I want 标记时间只改变二维码与链接的播放位置, so that 海报不额外出现时间标签。

27. As a 分享者, I want 标记更新期间保留旧预览并暂禁导出, so that 不复制与选项不一致的结果。

## Implementation Decisions

### 计划边界与已批准设计

- 此计划取代旧 A/B 视觉、与海报主题绑定的面板外观、海报分P/时间正文标记、Markdown勾选模式及旧降级反馈。保留其他已确认的用户脚本运行边界。
- 默认主题与面板分为两个对象：海报固定独立配色，面板仅依据页面有效浅深模式选择自己的统一配色。未来主题扩展不得在本轮恢复选择器。
- 第五版提供海报视觉基础；最终适配与第四版面板共同构成新基线。测试样例中的虚构标题、极限整数、比例尺封面和历史统计不进入生产数据。

### 海报渲染与内容适配

- 画布1080×1440；完整封面置于1080×608区域，以contain处理其他比例，雾蓝底色补空白。保留小尺寸官方蓝Logo（110×51）、粉色UP图标、官方形状的统计图标、原型圆角和署名层级。
- 标题采用同一原文字段，自动换行，按真实排版尝试64、60、56、52、48px；达到48px后按剩余可用高度省略。不能按分隔符推断主副标题，也不能将原型手工断行作为规则。
- 昵称最多两行，依次34、32、30px，达到下限后省略；完整值保留在相应文案字段中。统计、身份和二维码不可被覆盖。
- 统计按既有一位小数万/亿规则显示；缺项为 `--`。详细文案使用快照的精确整数及千分位，不从已缩写的海报数字逆推。
- 底部地址栏完整显示唯一share target，24px换行、不截断。普通样例页脚116px，压力样例可增高；先完成链接布局再测量标题区域，画布高度保持不变。最终原型的129px压力样例是证据，不是新硬上限。
- 分P/时间不出现在海报正文，不改变标题、封面、署名、统计或编号。仅二维码和底部链接随选项改变；较长链接引起的必要换行仍遵循完整显示规则。
- 二维码黑白、白底、保留静区；圆角作用于承托框，不能侵蚀有效码点和静区。预览与导出使用同一模型与布局，导出移除预览缩放。

### 分享目标、快照与一致性

- 打开时暂停并捕获原视频、分P、播放秒数、先前播放状态；标记切换不重新捕获播放位置、不重新取统计。时间向下取整，不产生 `t=0`。
- 默认两个标记关闭；规范目标只含必要的分P和时间参数。P2及以后启用时间需同时启用分P；关闭分P关闭时间。P1可独立启用时间。无法识别当前分P时允许默认分享，禁用依赖该上下文的标记并说明原因。
- 尝试短链并验证最终BVID、分P和时间；失败或不匹配时使用规范长链。不能为了消除提示而绕过目标验证，也不能将未复现的旧mismatch视作已修复。
- 海报二维码、可见链接、普通文案、Markdown和组合复制始终使用同一已确认目标。更新期间保留旧预览作占位并禁用导出，所有新输出一致后才恢复动作。
- 打开已有面板只聚焦；BVID或当前分P变化关闭并丢弃旧快照，异步旧结果不得重新挂载。所有关闭路径仅恢复脚本暂停过的同一视频/分P。

### 分享文案与复制动作

- “详细信息”控制既有详细文案级别，首次关闭、记住有效偏好；不改变海报内容或重新请求资源。
- 普通文案与Markdown是独立复制动作，不再存在Markdown勾选或持久模式。点击Markdown不改变普通文案预览，组合复制使用普通文案。
- 未被本轮明确删改的文案字段语义保留：紧凑普通文案含原始标题、UP署名和链接；详细信息含标题、UP、BV/AV、四项精确统计和链接，并保留原有条件上下文信息。海报不显示分P/时间的决定不自动删去已有详细文案字段。
- Markdown对同一信息级别进行编码，处理标题/昵称中的Markdown特殊字符；使用同一目标。原型的简化文案用于布局和动作验证，不将历史统计或省略的示例字段当作生产信息裁剪授权。
- 复制操作只能由用户点击触发；组合复制继续提供PNG、普通文本和兼容富表示。接收方决定粘贴结果，反馈不能保证所有目标都按先图后文粘贴。
- 组合写入失败时沿用普通文案降级并明确海报还需单独处理。独立Markdown复制失败时提供可选取的本次Markdown源文本作为手动路径，不能让用户误将普通预览当Markdown源。
- 旧偏好只恢复仍有效的详细信息选择；忽略旧A/B与Markdown模式值，不让其改变默认主题或本次复制动作。分P/时间仍每次打开重置。

### 面板与入口

- 桌面左预览右操作、窄屏纵向；16px居中标题、透明细线叉、小圆角、轻阴影、中性半透明遮罩。面板统一底色，无贯穿标题线或左右分隔线，使用留白组织内容。
- 两个标记开关置于操作区上方。“分享文案”右侧并列普通文案与Markdown复制动作；“详细信息”常显，不折叠。
- 底部并列复制海报和组合复制；下载为海报下方居中的图标。图标有可访问名称、悬停提示和键盘焦点。兼容性说明放在相关提示或动作反馈中，不增加口号与重复常驻说明。
- 入口保留在官方分享右侧，采用工具栏相近的行高、灰色图标/文字、蓝色hover，无独立描边矩形外壳。保持备用脚本菜单入口与SPA重挂载能力。
- 关闭按钮、Escape、点击遮罩共用关闭流程；键盘焦点不落入背景页面，关闭后返回可用入口。窄窗口允许滚动，动作不可被固定评议控件或窗口底部永久遮挡。
- 原型顶部/底部评议栏、样例选择器、外观模拟按钮、演示状态和测试元数据不进入产品。

### 失败与恢复

| 状态 | 预览和反馈 | 可用操作 |
|---|---|---|
| 首次生成 | 加载状态 | 关闭；生成结束前无导出 |
| 标记更新 | 保留旧预览并显示更新 | 关闭；一致性恢复前无导出 |
| 完成 | 当前海报与普通文案 | 全部动作 |
| 短链降级且长链有效 | 轻提示“已使用完整链接” | 全部动作 |
| 封面失败、必要文字和目标有效 | “封面暂时无法加载”，不输出占位成品 | 普通/Markdown文案复制、详细信息、重试、关闭；图像和组合动作禁用 |
| 关键身份/目标或播放器上下文失败 | 具体可操作错误与重试 | 重试、关闭；不可导出未验证信息 |
| 单次复制失败 | 保留预览/文案，指明替代操作 | 其他仍有效动作可继续 |

- 封面失败与metadata/目标失败必须区分。有效文案不以海报模型构建成功为前置条件；禁止以一个全局失败状态吞掉仍可用的文案路径。
- 重试保留原捕获上下文与当前选项，只重取允许刷新的生成资源。若导航已使上下文失效，则关闭，不对新视频进行恢复或旧快照重试。
- 开始修复时更正管理器封面域声明为官方支持的 `hdslb.com` 范围，继续保留API和短链所需精确域；不扩大为所有域。重新构建真实安装包并核对安装版本后验证原故障视频。
- 已有直接证据是管理器许可拒绝，未证明更正后整个解码/导出链路成功。记录必要的请求状态、有效类型/字节、解码尺寸及结果；详细诊断不常驻用户面板，不记录凭据。

### 页面外观与运行边界

- 支持当前标准视频页以及主人使用的BewlyCat场景：识别页面有效浅深模式，不逐项继承插件的自定义颜色。首次识别不能依赖已经错过的事件；打开后响应有效模式变化。
- 根节点标记、计算样式与已知主题事件是适配器候选信号，扩展私有事件只作刷新提示，不能作为唯一初始化来源。不能仅依赖会被清除的 `.bili_dark`，也不能将系统偏好当作站点显式设置。
- 信号失效保持当前已知模式，首次未知为浅色；不新增主题选择器或跨会话主题缓存。冲突/未知不能无依据切换已知模式。
- 保留标准 `/video/BV...`、Tampermonkey及既有Chrome/Edge支持范围。本轮不扩展番剧/影视/直播页面，不调用分享计数接口，不新增后端/遥测或自动更新服务器。

## Testing Decisions

### 接缝核对

沿用父规格已经由主人确认的**领域核心与浏览器副作用之间**这一接缝，无新增架构边界。现有目标、选项、领域模型、文案与复制结果测试提供先例；具体覆盖按本轮行为调整。真实字形测量和图片渲染留在浏览器侧，不以字符数单元测试伪装排版正确性。

好的测试从有效快照、用户动作或适配器结果出发验证可见结果；不固定私有类名、无业务意义的内部调用顺序或原型DOM结构。

### 领域与结果规则

- 分P/时间组合、默认目标、不可用上下文、时间取整、关闭分P联动及重开重置。
- 同一快照切换标记仅改变目标相关字段，不更换标题/封面/署名/统计/身份，也不产生海报正文标记。
- 短链有效/业务失败/错误BVID/丢失分P或时间/无效落点降级，所有输出共享同一目标。
- 详细信息对普通与Markdown的字段作用、格式转义、独立Markdown动作不改变普通/组合文案、有效偏好恢复与旧偏好忽略。
- 四项统计缺失/精确值/万亿缩写、文件命名、复制结果与兼容性提示规则。
- 输入为有效文字和目标但封面失败时，文案仍可生成，图像相关能力不可用；恢复成功后基于同一上下文解锁。

### 浏览器与真实安装验证

- 使用已批准样例类型检查导出尺寸、标题/昵称缩字与省略、非横版contain、完整长链换行、二维码静区和落点。验证真实导出PNG而不仅是预览DOM。
- 原故障视频在真实管理器安装包上重跑：确认连接许可、更正后的请求/解码/有效图片、海报显示及导出。故意失败的受控集成路径验证文案继续可用与重试恢复，不通过浅层尺寸测试宣称网络修复。
- 实际目标更新、重试、重复打开、关闭后异步完成、SPA换视频/换分P和播放恢复；验证不会导出旧状态或影响新视频。
- 当前页模式初始化、面板打开期间浅深切换、未知模式回退；补做可精确恢复的真实B站/BewlyCat设置切换，记录版本。现有CSS模拟和源码核查仅是前置证据。
- 真实用户手势下PNG复制、普通/Markdown复制、组合复制及失败替代路径；选代表性接收目标核实实际粘贴内容，不保证全部接收方。
- 桌面浅深、320/390px窄窗、可见焦点、图标名称、Escape和返回入口。视觉对照原型进行主人验收。

生产实现依票执行TDD、适当集成验证与code-review。此次规格合成未运行生产测试，也未将历史/原型通过状态记为新实现通过。

## Out of Scope

- 继续旧工单、直接合并原型或在规格批准前实施。
- 新主题选择器、A/B并存、重新设计已定稿海报、额外画布比例。
- 手工主副标题规则、海报正文分P/时间标签、图片裁切、视频帧提取、用户选图或生成封面兜底。
- 恢复Markdown全局模式、增加额外组合复制格式选择。
- 任意第三方主题扩展的全面兼容、以系统偏好替代站点偏好、修改用户站点/扩展设置作为产品实现。
- 新后端、内容上传、分享计数、遥测、自动更新服务器、支持范围外的页面类型。
- 将未复现的历史mismatch宣称已修复，或将静态原型当作真实安装验收。
