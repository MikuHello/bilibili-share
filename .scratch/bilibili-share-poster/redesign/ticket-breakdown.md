# 默认主题与分享面板改版 · 拆票方案

Status: APPROVED — seven-ticket breakdown accepted; tickets published; batch delivery
Date: 2026-09-05

依据已批准的[实现规格](./spec.md)。本拆票方案已获认可，正式工单已在本计划的 `issues/` 下逐票生成。旧工单不继续。

每票按完整用户路径实施并验收；必要的小范围预重构放在该票行为改动之前，不单独拆成不能演示的分层工程票。依赖表示行为验收的真实前置能力，不以修改同一文件作为阻塞原因。

## 01 — 恢复真实封面请求与图片导出

**Blocked by:** None — can start immediately.

**交付：** 更正封面域许可，构建并核对真实安装版本，在原故障视频走通请求、解码、预览到图片导出。此票可使用现有海报外观验收网络修复，不等待新设计。

**验收重点：** 不使用通配所有域；记录必要且无凭据的请求/解码证据；真实PNG有效。管理器许可修复不等于历史短链mismatch修复。封面失败的完整产品恢复路径由03承担。

**规格覆盖：** 56、57；11、43、55的基础链路。

## 02 — 落地唯一默认海报与完整内容适配

**Blocked by:** None — can start immediately.

**交付：** 用已批准默认海报替换A/B，真实快照生成预览及1080×1440导出；长标题、长昵称、非横版封面和完整长链接均遵守定稿规则。忽略旧海报主题偏好。

**验收重点：** 真实浏览器字体测量、有限缩字/省略、contain补底色、BV/AV及统计、二维码静区、链接完整换行。检查实际PNG和扫码落点，不仅检查DOM。海报正文不再包含分P/时间标签。可用受控真实图片验证，不以01联网修复为前置。

**规格覆盖：** 9–22、43；51的海报独立配色、58的旧主题偏好。

## 03 — 独立文案复制与封面失败恢复

**Blocked by:** None — can start immediately.

**交付：** 普通文案与Markdown分别复制，共享并记忆“详细信息”；封面失败时仍能复制两种文案、重试，并禁用所有图像及组合动作。重试保留捕获上下文和选项。关键身份/目标失败仍阻断导出。

**验收重点：** 先将有效文案与海报成功状态解耦，再完成可见行为。保留完整字段、精确统计及Markdown转义；移除全局Markdown模式，组合复制固定普通文案。复制失败提供对应格式的可选源文本。受控失败→文字可用→重试成功形成完整验证，不需要等待01来制造失败。暂沿用现有面板布局，最终位置由05落实。

**规格覆盖：** 15、19、33–38、45–49、58；57的可操作失败反馈。

## 04 — 标记仅更新统一分享落点

**Blocked by:** 02、03。

**交付：** 在新海报及两种文案路径上验证分P/时间组合：仅二维码与底部链接改变，所有文本分享链接同步；更新期间保留旧预览并禁止导出，完成后一次恢复一致结果。封面失败的文字路径同样正确更新。

**验收重点：** 默认关闭、P1/P2约束、未知分P、时间取整、切换不重取统计/播放位置；短链校验成功才采用，否则使用完整规范链接并轻提示。比较不应改变的内容，解码二维码核对目标；不把允许的链接换行误判为正文变更。

**依赖理由：** 需要02的新海报输出和03的独立文字/部分失败能力，才能验证完整输出集合的一致性。

**规格覆盖：** 22–30；38、46的目标一致性。

## 05 — 落地第四版操作面板与完整导出动作

**Blocked by:** 02、03。

**交付：** 按最终原型组织桌面/窄屏面板、标记选项、文案区独立复制按钮、常显详细信息、并列海报/组合复制及海报下方下载图标。真实复制、下载和失败替代路径可用，关闭与键盘导航完整。

**验收重点：** 原生式标题/细叉/背景/线条层级；无口号及原型评议控件；320/390px不遮挡动作。组合复制采用普通文案、失败降级说明准确；海报复制失败指向下载；真实用户手势验证代表性接收方，不承诺所有应用图文齐全。焦点限制、返回入口、Escape/遮罩、图标名称及禁用状态共同验收。

**依赖理由：** 需要02的最终海报预览/导出及03的双复制/失败能力来组成完整面板。04独立完善目标规则，不阻塞布局与动作路径落地。

**规格覆盖：** 31–45、53–54；46–49的最终状态展示。

## 06 — 跟随实际页面外观并融入原生入口

**Blocked by:** 05。

**交付：** 最终面板随B站/BewlyCat实际浅深模式切换；工具栏入口采用原生层级，保持官方分享与菜单备用入口、SPA重挂载。

**验收重点：** 打开时正确初始化、打开后响应变化、未知时保持上次有效模式/首次浅色；不以系统偏好替代页面设置，不新增选择器或主题缓存。真实设置切换可精确恢复并记录环境版本；海报导出保持独立配色。CSS模拟不能充当实际设置切换通过证据。

**依赖理由：** 在05最终面板结构上验证两种实际外观及焦点返回的真实入口。

**规格覆盖：** 1–4、50–52；54的入口可访问性。

## 07 — 保证更新、重试与导航时的快照生命周期

**Blocked by:** 03、04。

**交付：** 新增的部分失败重试和标记更新路径接入统一快照生命周期：重复打开只聚焦，导航关闭旧面板，迟到异步结果不复活旧内容，所有关闭方式仅恢复脚本暂停过的同一视频/分P。

**验收重点：** 播放/暂停两种初态、重复打开、重试中关闭、标记更新中导航、换视频/分P、迟到结果与重开重置。已有正确行为以回归证据保留，仅补齐新路径及发现的缺口，不预设已有实现全部失效。必要的生命周期保护不能等到本票才允许前序票运行；本票负责跨新路径的完整生命周期验收和收敛。

**依赖理由：** 必须有03的重试和04的异步目标更新，才能实际验证两类新增流程的导航/取消竞态；不依赖05的视觉结构或06的配色。

**规格覆盖：** 5–8、48–49；23、27、53的跨路径回归。

## 共同完成条件

- 55及所有Out of Scope约束对每票生效：本地生成，不增加后端/上传/遥测或扩大支持页面。
