- 标题保持宽栏、完整自动换行；清晰封面位于标题下方，轻微向右错位，保留原图比例并contain展示。
- 背景来自同一封面，经240×320小画布模糊后生成一次背景图；叠加半透明浅色层保障深色文字可读。取色继续决定文字倾向，不固定浅蓝浅绿。
- 3:4画布；左上logo、右上BV/av、大号信息栏、完整目标链接；分P/时间只改变目标与二维码。
- 保留面板独立浅深色与取消文案空行。按钮仅模拟，无实际剪贴板写入、下载或生产集成。
- 使用历史封面与二维码素材，上传封面只比较构图与配色，仍保留样例元数据。系统字体回退、极长标题、跨系统导出和多种真实封面的最终验收尚待后续。
