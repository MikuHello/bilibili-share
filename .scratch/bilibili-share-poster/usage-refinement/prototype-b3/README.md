# B第三版：稳定封面与独立标题区

Status: prototype ready for review; not approved production spec

预览：http://127.0.0.1:8771/prototype-b3/
启动：仓库根运行 `python3 -m http.server 8771 --bind 127.0.0.1 --directory .scratch/bilibili-share-poster/usage-refinement`。

主人认可的方向：封面在上，标题在下，共同对齐；固定画布，有限缩字后省略，完整标题保留文案；模糊封面背景连续。

原型把3:4画布划分为固定比例的标识、封面、标题、信息、链接区域。封面contain完整显示；标题按实际高度测量从6.0到4.4cqw分档缩字，最低档放不下才二分寻找可容纳的省略位置。参数仍待视觉评议，不是生产排版规格。

底部可切换短/原始/长/极长标题，横版历史封面/600×600方形合成测试图/400×800竖版合成测试图，也可换入本地封面。合成图用于画幅压力检查，不代表已验证不同真实视频的设计质量。上传后元数据仍为样例。

证据：../evidence/b3-report.json。桌面12组合标题均容纳，封面和页脚位置不变；390px无横向溢出。../evidence/b3.png 与 b3-mobile.png为浏览器截图。没有正式PNG导出、剪贴板、真实网络或用户脚本集成验收。

复制与下载按钮仅演示；旧B2和ABC保留为历史对照。

标题区改为内容高度并有上限，分隔线随标题结束位置上移；信息区承接余量并居中。封面仍稳定，页脚位置不再承诺不变。署名、数字、UP与统计图标均放大；最新规则以本段及idea.md第六轮为准。
