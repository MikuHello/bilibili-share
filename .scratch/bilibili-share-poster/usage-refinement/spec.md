# 分享海报实测改进 · 实现规格

Status: approved — implementation spec and ticket breakdown approved; tickets published

视觉基线：主人已确认当前B3原型满意并结束设计探索。主人随后回复“批准”，本实现规格获批；拆票方案仍待审阅。

## Problem Statement

分享海报实际使用中存在深色文字难读、操作提示挤动页面、入口不协调、标记切换卡顿、短链引入额外等待、组合复制没有达到图文一起粘贴的预期。海报固定雾蓝配色不能匹配不同封面，编号位置、长短标题适配以及信息图标大小和统计换行影响质量。

## Solution

交付单一的B3默认海报：清晰封面在上，完整标题在下，共用对齐线；背景由当前封面模糊生成并控制明暗。标题高度自适应，分隔线随标题走；UP主独立一行，四项统计同排，信息图标尺寸与标题长度无关。分享面板与页面入口正确适配浅深色，完整链接统一所有输出，短促浮层反馈不影响布局。通过缩小更新范围、去除短链依赖与按版本复用生成结果改善交互，并保持快照和导出一致性。

## User Stories

1. As a 分享者, I want av前缀小写、BV标识保持原样, so that 编号规范且可辨认。
2. As a 分享者, I want logo在左上、BV和av在右上, so that 身份信息一眼可见。
3. As a 分享者, I want 清晰封面完整展示且保持比例, so that 内容不被随意裁切。
4. As a 分享者, I want 背景来自当前封面, so that 海报色彩与视频一致。
5. As a 分享者, I want 模糊背景上的文字清楚, so that 氛围不牺牲阅读。
6. As a 分享者, I want 标题在封面下方并与其对齐, so that 长标题不让构图失衡。
7. As a 分享者, I want 短标题下方分隔线自然上移, so that 不必为长标题预留大片空白。
8. As a 分享者, I want 超长标题有限缩字后省略, so that 固定画布不被撑坏。
9. As a 分享者, I want 文案保留完整标题, so that 海报省略不造成信息丢失。
10. As a 分享者, I want UP主独立一行, so that 署名清楚。
11. As a 分享者, I want 四项统计固定同排, so that 信息整齐而不零散换行。
12. As a 分享者, I want 信息图标足够大且不随标题变化, so that 阅读稳定。
13. As a 分享者, I want 缺失统计显示--、真实零保持零, so that 数据含义准确。
14. As a 分享者, I want 海报链接与二维码使用同一完整目标, so that 两种访问方式一致。
15. As a 分享者, I want 分P与时间标记保留既有语义, so that 分享落点正确。
16. As a 分享者, I want 标记更新不改变封面、标题和统计, so that 生成快照稳定。
17. As a 分享者, I want 正文后下一行直接出现链接, so that 分享文案没有多余空白。
18. As a 分享者, I want 普通与Markdown独立复制, so that 按接收场景选择格式。
19. As a 分享者, I want 深色面板的标题、文字、图标和控件清楚, so that 夜间易于使用。
20. As a 分享者, I want 生成海报入口融入原操作栏, so that 功能看起来协调。
21. As a 分享者, I want 下载图标紧邻复制海报左侧, so that 导出动作集中。
22. As a 分享者, I want 操作结果以利落浮层出现, so that 页面不会被提示挤动。
23. As a 分享者, I want 标记控件即时反馈且不反复重建, so that 操作没有分批加载感。
24. As a 分享者, I want 更新期间不能导出混合状态, so that 图片和链接始终一致。
25. As a 分享者, I want 重复导出同一海报复用结果, so that 不必重复等待。
26. As a 分享者, I want 通用图文复制经过实际粘贴验证, so that 写入提示不冒充可用效果。
27. As a 分享者, I want 难以实现的组合复制可以舍弃, so that 产品不为它增加平台专用适配。
28. As a 分享者, I want 复制失败后仍有明确替代路径, so that 分享可以继续。
29. As a 分享者, I want 窄屏下仍可访问动作且键盘操作完整, so that 窗口尺寸不阻断操作。
30. As a 维护者, I want 配色、目标推导、导出和面板职责集中, so that 后续迭代无需跨多处重复修补。

## Implementation Decisions

### 基线与范围优先级

- 以已确认B3最新原型为视觉事实源；它替代旧固定雾蓝、下方编号、短链优先、下载置于海报下方及早期固定标题区决定。原型中的测试选择器、样例控制、演示文案不进入产品。
- 实现起点应核对delivery候选版本，而非直接修改仍有A/B主题的旧主分支。保留已有未提交材料，隔离实施；记录实际安装版本与构建对应关系。
- 继续1080×1440导出、标准视频页、Tampermonkey、现有Chrome/Edge支持范围。未被本规格替代的快照、导航、分P/时间、播放器恢复、失败恢复规则继承先前批准规格。

### 海报布局与颜色

- 仅一个默认设计，不新增A/B/C选择器。面板浅深外观与海报配色独立；页面切深色不改变分享海报内容或背景。
- 清晰封面保留全图，固定上方展示区，非横版居中contain；背景可对封面副本放大、模糊，不修改清晰封面。
- 背景在封面解码后以低分辨率图像生成模糊色彩，并加明暗控制层。按封面复用处理结果；避免持续大图实时滤镜。原型的小画布与模糊半径是起点，最终参数须通过真实导出验证，不能只验证预览DOM。
- 标题自动换行，不手工拆主副标题；使用原型衬线标题、无衬线信息的层级。根据真实字体测量有限缩字，最低字号后使用真实省略字符。测量在不可见节点完成，不在可见标题上反复试写；原始完整标题保持不变。
- 标题区按内容收紧并有上限；分隔线随标题下缘移动。封面区不随标题行数位移，信息区可随分隔线上移；不再承诺页脚固定坐标。
- 原型当前标题上限相当于画布高度26%，字号约为画布宽度6.0/5.6/5.2/4.8/4.4%；实现转换为导出坐标并核对，不依赖预览容器偶然宽度。
- UP署名独立一行。四项统计顺序为播放、点赞、投币、收藏，固定同排且不换行；图标禁止flex压缩，其尺寸只随整张预览缩放，不受标题或数字长度影响。
- 最终原型署名字号约4.6%、UP图标6.2%、统计字号3.4%、统计图标5%、二维码17%、二维码说明及地址字号2.5%，均相对画布宽度。极端昵称和统计需在既有有限适配规则内验证，不允许图标变小或统计换行来掩盖溢出。
- 保持二维码白底和静区；完整链接允许换行但不省略，不与二维码或统计冲突。实际PNG需可扫描，目标与其他输出相同。

### 分享目标与文案

- 全面移除短链请求、解析、校验、回退提示、缓存与仅为短链保留的连接权限。保留视频身份及canonical目标验证，删除短链不能删除必要安全校验。
- 默认链接使用canonical视频地址；分P与时间按既有约束生成参数。时间向下取整；P2及以后时间依赖分P；关闭分P联动关闭时间；重开重置标记。
- 海报可见链接、二维码、普通文案、Markdown和保留时的组合复制共用一个目标。
- 标记只改变目标相关输出，不改海报标题/署名/统计，也不插入分P或时间正文标记。详细文案中的条件信息按既有规则保留。
- 正文与链接之间只有一个换行，无空白行或段落间距。普通预览与复制一致；详细和Markdown同样取消该处冗余空行，不破坏Markdown语义或转义。
- av小写用于用户可见编号，BV标识保持原样；不修改身份数值或引入新的BV转换逻辑。

### 面板、反馈与状态

- 下载图标位于蓝色复制海报按钮左侧；组合动作是否存在遵循下述证据规则。入口与原工具栏图标、基线、尺寸和交互状态协调。
- 主动定义面板标题、正文、图标、背景和控件颜色，防止宿主标题样式造成深底黑字。维持已批准页面有效模式识别，验证初始化与模式切换。
- 成功/失败操作反馈使用不参与布局的浮层；约120ms的短过渡作为原型基线，支持减少动态效果，不用动画等待阻塞数据完成或按钮恢复。重要失败须保留可操作恢复路径，不能仅闪现后消失。
- 保持关闭、Escape、遮罩、焦点返回与窄屏可达性。浮层不遮挡关键控件，不增加常驻技术说明。
- 保持稳定的面板控件节点，详情变化只更新文案，目标变化仅更新必要输出。异步结果按快照/目标版本判定过期，关闭或导航后不得回写；复制时只使用一致的已完成版本。

### 工程策略与性能

- 本规格提出保留现有TypeScript、原生DOM、二维码与DOM转PNG方案，进行局部职责调整；调查尚未证明需要换框架或整体重写。规格批准包含对该工程策略的审阅。
- 优先复用现有领域核心与浏览器副作用之间的测试接缝，不新增泛化架构层或仅转发调用的模块。
- 同步目标/文案推导、封面衍生颜色、海报排版与按版本导出、面板交互/反馈分别有清晰职责；目录组织服务于修改集中，而非先规定目录层级。
- 同一封面复用解码及背景；同一完成海报版本复用PNG结果或进行中的导出Promise。失败可重试，封面/版式/字体/目标变化使相应缓存失效；资源随快照释放，禁止无限跨视频积累。
- 移除标记路径短链网络与人为140ms串行等待。完成前保留旧预览但禁用不一致导出；控件反馈不等整张海报重建才出现。
- 不以隔离样例计时充当真实使用性能承诺。实现前后在相同环境分别记录打开、标记切换、首次/重复导出的阶段耗时、长任务和布局变化；报告样本、环境、失败与差异，不编造p95或未经确认的硬时限。

### 组合复制的证据决策

- 只使用通用标准Web剪贴板能力，不添加QQ、Windows、macOS专用格式/分支或原生桥接。原型中出现组合按钮不是无条件保留的批准。
- 实现前先做一次有边界的通用方案验证。现候选已有PNG、text/plain和HTML，不把重复添加三格式当成修复。记录API是否写入、实际粘贴是否有图片、是否有独立可编辑文字；mock不能作为粘贴成功证据。
- 能以通用方案达到目标则保留，反馈明确接收端兼容边界；验证表明难以可靠达到目标则按主人既有授权移除组合入口，独立复制与下载保留，底部动作自然填充。
- 缺少真实验证环境只表示证据不足，不等于不可行，也不能宣称已修复；应在交付前明确该验证缺口，不将平台适配作为补救。
- 保留时沿用写入失败的明确降级路径；所有剪贴板写入只来自用户操作。

## Testing Decisions

- 沿用先前批准的领域核心与浏览器副作用之间的接缝，当前不新增架构接缝；此次规格审阅一并确认此沿用方案。领域结果从有效快照、选项、适配器结果进行验证；浏览器布局、字体、PNG和粘贴在浏览器层验证。
- 复用现有目标生成、文案、选项联动、生命周期及剪贴板结果的测试先例。测试对外行为和可见结果，不固定文件数、私有类名、DOM搭建顺序或mock内部调用链。
- 验证canonical单一目标、所有输出一致、av大小写、无空行、Markdown转义、分P/时间联动及不再请求短链。
- 验证详情变化不触发图像/网络工作，重复同版本导出复用，失败可重试，版本切换失效，旧异步任务不能覆盖新状态。
- 用短/普通/长/极长标题与横/方/竖封面组合，补充真实深色、暖色、低饱和、高对比封面、长昵称、极端数字、缺失值、长目标。检查完整封面、标题有限适配、分隔线位置、图标恒定、四统计同排、二维码避让与实际扫码。
- 检查浅深初始状态与切换、宿主样式干扰、320/390px窗口、键盘焦点、反馈无布局位移、减少动态效果。
- 原型现有12组合、图标尺寸与同排报告是设计证据，不替代生产PNG或真实用户脚本验收。偶发原型标题回跳未复现，不宣称已修复；生产增加过期结果与可见标题稳定性验证。
- 实现阶段逐票TDD、类型检查、适当浏览器集成、双轴code-review；最终真实构建统一验收。剪贴板接收端与安装版本核对仍需真实证据。

## Out of Scope

- 继续设计新主题、恢复A/B/C切换、动态画布尺寸、手工拆标题、裁切清晰封面、生成替代封面。
- 平台/应用专用组合复制适配、后端、上传封面、遥测、自动更新或扩大页面支持范围。
- 无证据的框架迁移、整体重写、按目录美观进行重构。
- 将原型演示代码直接合并生产，或把设计满意等同于实现规格及拆票批准。
