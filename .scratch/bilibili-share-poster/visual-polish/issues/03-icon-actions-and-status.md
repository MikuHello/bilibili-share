# 03 — 图标动作按钮与瞬时状态反馈

**What to build:** 动作区为**三个**按钮：复制海报（主）、下载（仅图标）、海报+文案；纯文字复制移出动作区，改为文案预览卡右上角的小复制图标。hover/focus 显示 tooltip；动作反馈为动作区下方的瞬时状态，成功自动淡出、失败保持。删除常驻说明段落。

**Blocked by:** 01 — 修正入口并建立海报舞台面板骨架；02 — 选项 pill 与可读的文案预览卡（文案卡角标复制依赖 02 的卡片结构）

**Status:** ready-for-agent

- [ ] 动作区为**三个**按钮，宽视口一行三列、窄视口按网格明确换行；按钮统一高度 44px，任何宽度不挤压或溢出。
- [ ] 三个动作：
  - **复制海报**（主，实心强调）— 海报 PNG 进剪贴板，图标 + 短标签。
  - **下载** — 仅下载图标，无「下载 PNG」文字标签，下载语义由图标自解释；有 `aria-label`。
  - **海报+文案**（原组合复制改名）— 海报图 + 文字打包进剪贴板，图标 + 短标签。
- [ ] 复制海报与海报+文案为并列的两种风格，复制海报略突出（实心主按钮）。
- [ ] **「复制文案」不在动作区**：纯文字复制改为文案预览卡右上角的一个小复制图标（内联引导），图标有 hover/focus 态与成功/失败反馈；因为文字在该卡内已可见、可选中。
- [ ] hover/focus 有明确状态与 tooltip（tooltip 补充，不替代可见标签；下载按钮靠图标）。
- [ ] 复制/下载成功反馈显示在动作区下方，约 3 秒后淡出；失败保持到下一次操作。
- [ ] 剪贴板失败路径不回归：海报复制失败仍引导下载；组合（海报+文案）复制失败仍退化为仅复制文案；文案卡角标复制失败时精确文本保持可见、可选中并提示手动复制。
- [ ] 固定帮助句“预览、复制和下载使用同一已生成海报…”移除。
- [ ] 纯逻辑测试覆盖动作状态文案映射；`npm test`、`npm run check`、`npm run build` 通过；真实页面三个动作 + 文案卡角标复制 smoke 通过。
