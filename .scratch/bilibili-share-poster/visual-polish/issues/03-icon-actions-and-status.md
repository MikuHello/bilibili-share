# 03 — 图标动作按钮与瞬时状态反馈

**What to build:** 四个导出动作改为“图标 + 短标签”按钮，复制海报为主操作；hover/focus 显示 tooltip；动作反馈为动作区下方的瞬时状态，成功自动淡出、失败保持。删除常驻说明段落。

**Blocked by:** 01 — 修正入口并建立海报舞台面板骨架

**Status:** ready-for-agent

- [ ] 动作区为 2×2 或一行自适应网格，按钮统一高度 44px，任何宽度不挤压或溢出。
- [ ] 四个动作：复制海报（主）、下载 PNG、复制文案、组合复制；每个按钮图标 + 可见短标签，纯图标形态不采用。
- [ ] 主按钮实心强调，其余描边/浅底；hover/focus 有明确状态与 tooltip。
- [ ] 所有按钮有 `aria-label`；tooltip 不替代可见标签。
- [ ] 复制/下载成功反馈显示在动作区下方，约 3 秒后淡出；失败保持到下一次操作。
- [ ] 剪贴板失败路径不回归：海报复制失败仍引导下载；文案复制失败仍可手动选择；组合复制失败仍退化为仅复制文案。
- [ ] 固定帮助句“预览、复制和下载使用同一已生成海报…”移除。
- [ ] 纯逻辑测试覆盖动作状态文案；`npm test`、`npm run check`、`npm run build` 通过；真实页面四个动作 smoke 通过。
