# Bilibili 分享海报 · 交互与视觉打磨 spec

Status: approved（2026-08-17；入口、分享面板、动作区、动效与响应式部分）

> 范围声明：本 spec 只覆盖页面入口、分享面板、选项/文案/动作控件、主题切换动效、封面缺失占位与响应式布局。海报 A/B 画面内容本身仍由既有 `.scratch/bilibili-share-poster/spec.md` 约束，后续单独讨论，不在本 spec 中重做。

## Problem Statement

当前 userscript 功能完整，但视觉与交互达不到可用标准：入口被插在分享图标下方；面板堆叠大量说明文字；四个导出动作像独立栏目；文案预览像原始 Markdown 代码块；B 方向底部控制条溢出；主题切换时海报跳动。需要把 A 方向“结构清楚、控制区可读”和 B 方向“海报是主角、舞台沉浸”合并为一个最终方向，并用明确的样式规范保证任何宽度下都不溢出。

## Solution

一个 **海报优先的混合面板**：左侧/上方是深色中性海报舞台，右侧/下方是干净的控制栏。控制栏使用与当前主题一致的 tokens（A 暖纸、B 深色），只保留眉题、主题切换、四个选项、文案预览、四个动作和瞬时状态反馈。页面入口成为官方分享按钮同排的真实 toolbar item。所有动作采用**图标 + 可见短标签**，不采用纯图标或四字文本块。主题切换使用双层 crossfade，海报不跳、布局不变。封面缺失时使用安静的中性占位。

## User Stories

1. As a 视频观看者, I want 入口位于官方分享按钮右侧同一排, so that 它看起来是页面工具栏的一部分而不是插入的异物。
2. As a 视频观看者, I want 面板只显示一行 `BILIBILI SHARE` 眉题, so that 界面干净且没有重复标题。
3. As a 视频观看者, I want 海报在深色中性舞台上呈现, so that A/B 海报都像被展示而不是贴在表单里。
4. As a 视频观看者, I want 宽屏下控制栏在右侧、窄屏下控制栏在下方, so that 任何宽度下按钮都不溢出或挤压。
5. As a 视频观看者, I want 主题切换是交叉淡化而不是跳动, so that 视觉连续且不产生布局位移。
6. As a 视频观看者, I want A/B 分段控件使用 `A 报刊` / `B 沉浸`, so that 主题选择一眼可辨。
7. As a 视频观看者, I want 四个选项用带图标的 pill, so that 没有副标题也能理解状态。
8. As a 视频观看者, I want 文案预览看起来是设计过的消息卡而不是代码块, so that 我能快速读懂将要复制的内容。
9. As a 视频观看者, I want 四个导出动作使用图标 + 短标签, so that 第一眼就知道每个按钮的作用。
10. As a 视频观看者, I want 动作反馈只出现在动作区附近并自动淡出, so that 界面没有常驻说明段落。
11. As a 视频观看者, I want 短链降级提示只在降级时出现, so that 正常路径没有噪音。
12. As a 视频观看者, I want 封面缺失时显示安静占位与极小的 `COVER UNAVAILABLE`, so that 海报不破损且保持自解释。
13. As a 视频观看者, I want 动效遵循 `prefers-reduced-motion`, so that 偏好减少动效的用户不被干扰。

## Implementation Decisions

### 页面入口

- 插入点：`.toolbar-left-item-wrap` 之后，作为其兄弟节点；不再插入到 `.video-share-wrap` 内部。
- 形态：与官方工具栏同高（约 34px），内含 18px 海报图标 + `生成海报`，A 状态为白底细边框，B 状态为深色实心；hover/focus 有明确状态。
- 挂载保持幂等；SPA/DOM 重建时恢复。

### 面板结构

- 面板最大宽度 1040px，最大高度 `calc(100vh - 56px)`，圆角 16px，使用共享 tokens。
- 头部 52px：左侧 `BILIBILI SHARE` 眉题（10px 等宽大写字距），右侧关闭按钮。不保留大标题。
- 宽视口（≥ 880px）：
  - 网格 `54% / 46%`。
  - 左侧：海报舞台，深色中性 `#232629`，内边距 24px，海报宽度 `min(100%, 360px)` 居中，带柔和投影。
  - 右侧：控制栏，垂直排列，内边距 20px 22px，自身滚动。
- 窄视口（< 880px）：
  - 单列：海报舞台在上，控制栏在下。
  - 控制栏使用 `grid` 明确换行：选项 2×2，动作 2×2；任何单项 `min-width` 不压破容器。
  - 面板最大高度为视口高度，整体滚动；底部操作始终可达。
- B 原型的底部绝对定位控制条**不采用**；所有控件都位于正常文档流中。

### 控制栏

- 顺序：主题分段控件 → 选项 pill → 降级提示（条件）→ 文案预览卡 → 动作区 → 状态反馈。
- 主题分段：`A 报刊` / `B 沉浸`，激活态使用主题强调色。
- 选项：4 个图标 pill，文案仅 `分P`、`时间戳`、`详细`、`Markdown`；`aria-pressed` 表达开/关。
- 动作：4 个按钮，每个为 **图标 + 短标签**：
  - 复制海报（主）、下载 PNG、复制文案、组合复制。
  - 主按钮实心强调；其余描边/浅底。
  - 按钮统一高度 44px，宽视口单列 2×2 或控制栏宽度允许时一行；窄视口 2×2。
  - tooltip 仅作为补充，不能替代可见标签。
- 状态反馈：动作区下方单行，成功约 3 秒后淡出；失败保持到下一次操作。无固定帮助段落。

### 文案预览卡

- 视觉上是一张消息卡：系统中文字体、正常行高、浅色底/深色模式对应。
- 标题与 UP 主部分使用 UI 字体；链接行使用等宽字体并以低对比强调色显示。
- 内容必须与实际复制文本逐字符一致；使用 `white-space: pre-wrap`，不做语法高亮、不加代码块边框。
- 高度上限约 96px，超出滚动；不额外添加“预览”标题。

### 主题与动效

- 完整参数见 `motion.md`。
- 主题切换：
  - 旧海报保持在原位；
  - 新海报在独立图层先渲染；
  - 旧层 160ms 淡出、新层 160ms 淡入，可选 4px 上移；
  - 动画结束后移除旧层；面板 tokens 颜色 180ms ease 过渡。
  - 不允许通过先清空再重建造成跳动。
- 面板打开/关闭、状态反馈、入口 hover 均按 motion.md 执行。

### 封面缺失

- 判定：解码失败、自然尺寸小于 160×90、或 1×1 透明占位图视为不可用。
- 处理：海报封面区域显示中性纹理 + 极小 `COVER UNAVAILABLE`；面板不报致命错误，复制/下载仍可用。
- 未来生成视频缩略图作为独立 ticket，本 spec 不实现。

### 测试 seam

- 纯逻辑：封面可用性判定、主题 tokens 选择、选项状态、动作/状态文案映射，放入 Node 测试。
- DOM 布局、动画、tooltip、响应式为薄适配器，由真实页面与视觉验收确认，不做 DOM 单元测试。
- 真实页面 smoke 覆盖：入口位置、宽窄视口、A/B 切换、四个动作、封面缺失、短链降级。

## Out of Scope

- 海报 A/B 画面内容重做。
- 视频帧缩略图生成。
- C 方向。
- 前端框架或动画库。
- 更多主题或页面环境自适应变体。
