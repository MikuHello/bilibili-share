# Bilibili 分享海报

在 Bilibili 标准视频页生成分享海报，并分别复制海报、普通文案或 Markdown。

## 功能

- 使用视频封面、标题、UP 主和公开统计信息生成分享海报。
- 预览并复制海报，或下载 1080×1440 PNG。
- 二维码与可见链接指向同一视频，支持标记当前分P和播放时间。
- 普通文案与 Markdown 独立复制，可选择是否包含详细信息。
- 分享面板跟随页面明暗模式。

## 使用

安装并启用 Tampermonkey 后，访问 Bilibili 标准 BV 视频页，点击官方分享控件附近的“分享海报”。在面板内选择分享选项，再复制或下载所需内容。

目前面向标准视频页，不支持番剧、直播等其他内容页。文案模板自定义暂面向开发者，尚无图形设置界面。

正式安装和更新以本 Greasy Fork 页面为准。
