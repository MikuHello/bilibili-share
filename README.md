# Bilibili Share

An idea-stage project for adding an image-poster sharing action beside Bilibili Web's official share control.

Product discovery starts at [`.scratch/bilibili-share-poster/idea.md`](.scratch/bilibili-share-poster/idea.md). The repository uses Matt Pocock's project-level skills and a local-Markdown issue tracker; see [`docs/agents/skills.md`](docs/agents/skills.md).

No runtime, browser integration, or visual direction has been selected yet.
