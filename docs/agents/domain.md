# Domain docs

This is a single-context repository.

Before exploring or changing product behavior, read:

- `CONTEXT.md`, when present, for resolved domain vocabulary;
- relevant records in `docs/adr/`, when present, for durable decisions;
- the active idea, spec, or ticket under `.scratch/`.

Missing domain files are expected during early discovery. Create `CONTEXT.md` only when a term has been resolved, and create an ADR only for a hard-to-reverse decision. Use the glossary's chosen terms consistently and surface any conflict with an existing ADR.
